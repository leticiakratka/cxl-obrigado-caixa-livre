# Caixa Livre — Página de Obrigado

Página de obrigado pós-compra do Caixa Livre. Confirma a compra e conduz o cliente direto pro diagnóstico rápido (menos de 2 min), reaproveitando a engine de perguntas e o roteamento do form de onboarding.

- `index.html` — página completa (boas-vindas + diagnóstico + roteamento)
- `apps-script.gs` — backend que grava as respostas na planilha
- GTM server-side instalado (head + noscript)
